# Résumé project entry

**SentinelFlow — AI-Assisted SOC Detection & Automation**  
*Splunk Enterprise, n8n, Windows Security Logs, Sysmon, Kali Linux, Google Gemini, Slack, Docker*

- Built a self-hosted SOC automation lab across Windows and Ubuntu VMs, integrating Splunk REST searches with n8n scheduled workflows and Gemini-assisted security triage.
- Developed a lab-specific Windows Event ID 4625 detection rule; validated the pipeline using two controlled unsuccessful RDP authentication attempts, with matching Splunk evidence and automated Slack notification.
- Implemented alert grouping, severity routing, duplicate suppression, request retries and Slack-based workflow failure reporting; documented known licence and delivery-reliability limitations.

Do not present this as production deployment, autonomous response or general attack prevention.
